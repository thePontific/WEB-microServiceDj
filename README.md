**Лабораторная работа №8. Асинхронный сервис и интерфейс модератора.**

**Цель:** Внедрение асинхронности, выделенного сервиса и интерфейса для модератора.

**Задание:**
1.  Разработать асинхронный сервис на другом языке (на Django) с одним HTTP-методом.
2.  Сервис должен имитировать долгий расчет (5-10 сек.), и возвращать результат.
3.  В основном бэкенде добавить метод для приема результатов от асинхронного сервиса (с простой проверкой по токену).
4.  В методе завершения заказа PUT вызывать асинхронный сервис и обновлять поле скорости после получения ответа.
5.  Обновить диаграммы развертывания и последовательности.
