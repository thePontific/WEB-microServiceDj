# Микросервис расчетов для «Андромеда» (Lab 8)

## 🧠 О сервисе
Это **вычислительное ядро** проекта, реализованное в рамках лабораторной работы №8. Микросервис отвечает за все математические расчеты, связанные с моделированием вращения галактики Андромеда.

## 🔗 Интеграция
Сервис предназначен для использования **бэкенд-шлюзом (`WEB-Backend`)**. Все запросы к расчетам должны идти через основной бэкенд на Go, который выступает прокси и агрегатором данных.

## 📈 Научная реализация
В основе расчетов лежит алгоритм, преобразующий радиальный профиль светимости галактики в профиль масс, с последующим вычислением орбитальных скоростей звезд на разных радиусах.
